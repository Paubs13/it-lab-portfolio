# IT Support Home Lab — CompTIA A+ Portfolio

Hands-on virtualized lab environment built to demonstrate core IT support
competencies mapped to the CompTIA A+ Core 1 & Core 2 exam objectives.

## Environment
- Oracle VirtualBox 7.x
- Windows 10 Pro (22H2) client VM
- Windows Server 2022 Standard Evaluation (DC)
- Internal network: 192.168.10.0/24

## Scenarios Completed
| # | Scenario | A+ Objective |
|---|----------|--------------|
| 01 | Active Directory Domain Setup | 2.6 |
| 02 | User Account & Permission Management | 2.7 |
| 03 | BitLocker Drive Encryption | 2.3 |
| 04 | Malware Simulation & Remediation | 2.8 |
| 05 | OS Break & Recovery | 3.1 |
| 06 | Firewall Rule Configuration | 2.10 |
| 07 | OS Hardening Checklist | 2.5 |
| 08 | PowerShell Automation Script | 4.8 |

Active Directory | BitLocker | Windows Firewall | PowerShell |
